FIELD MANUAL

Information

This manual explains the website's statistics, assumptions, and calculations.

Number Formatting

Numbers are displayed to a maximum of two decimal places. Hover over graph point values and calculated table results to see ten decimal places. Calculations use the unrounded values.

Weapon Range Terms

  • Base damage: damage before falloff begins.
  • End damage: damage at the drop-off plateau.
  • Damage differential: base damage minus end damage.
  • Drop-off cliff: distance where damage falloff begins.
  • Drop-off plateau: distance where end damage is reached.
  • Drop-off rate: average damage lost per metre between the cliff and plateau.

Weapon Performance Terms

  • bTTK: bodyshot-only time to kill.
  • hTTK: headshot-only time to kill.
  • eTTK: expected TTK without misses.
  • vTTK: expected TTK including misses.
  • DPS: damage per second under the specified firing assumptions.
  • STK: shots to kill.

Accuracy Assumptions

Weapon pages accept multiple UIDs, deduplicate them, and average valid per-player accuracies equally. Daily collection walks the public lifetime rankings, then fetches each discovered profile. This is ranking-discoverable coverage rather than all registered accounts; a complete pass can take multiple days. Each profile supplies observations for every supported weapon, without extra requests per weapon. The last complete baseline remains active while a new pass runs.

Data and Estimates

Reference statistics should be verified against reliable game data. Estimated damage curves will be labelled as estimates until the actual damage curve is confirmed.

Engagement metrics

Expected shots to kill includes misses. Expected kills per magazine counts completed kills against consecutive fresh targets and discards excess damage from killing shots. Magazine size is adjustable; this also updates one-magazine probability and reload timing. Median and 90th-percentile TTK come from a discrete shot-outcome distribution.

Weapon-specific limitations

Unknown falloff curves use an explicitly labelled base-damage scenario. Shotguns use manual independent-pellet probabilities, not API accuracy counters. Launchers expose reference facts without ordinary rifle TTK predictions. Projectile flight, spread correlations, burst timing and shell-by-shell reloads are not verified.
